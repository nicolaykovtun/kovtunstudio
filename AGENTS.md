# Проверка опубликованного сайта

Перед проверкой сайта kovtun.studio в рабочем браузере откройте адрес
`https://kovtun.studio/?ks_metrika_internal=1`. Он отключает счетчик Яндекс
Метрики для этого браузера, чтобы рабочие просмотры не попадали в статистику.
Повторите при новом профиле, в режиме инкогнито или после очистки данных сайта.
Если браузер не сохраняет данные сайта, используйте этот параметр при каждом
открытии страницы. Для возврата обычного учета используйте
`https://kovtun.studio/?ks_metrika_internal=0`.

По возможности проверяйте верстку на локальном превью.
