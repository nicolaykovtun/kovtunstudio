Данные для упаковки линейки

Одна страница на все вкусы. Заполните общие данные один раз, затем по каждому вкусу состав, пищевую ценность и штрихкод. Страница сразу показывает, чего не хватает для вёрстки и что обязательно по техрегламенту.

Всё считается в браузере. Пока вы не нажали «Отправить в студию», данные никуда не уходят и не сохраняются: закроете вкладку, они пропадут. Чтобы вернуться позже, нажмите внизу «Скачать файл», а потом откройте его кнопкой «Продолжить из файла».

1. Общее для всей линейки

Заполняется один раз. Если у какого-то вкуса другой изготовитель, укажите это в его вкладке в поле «Особенности».

2. Вкусы

Каждый вкус в своей вкладке. Счётчик на вкладке показывает, сколько обязательных полей заполнено. Если значение одинаковое для всех вкусов, нажмите под полем «Вставить во все вкусы».

3. Заявления на упаковке

Всё, что вы хотите написать о пользе и качестве: «источник белка», «без сахара», «греческое оливковое». Писать их не обязательно, но каждое заявление на пищевой упаковке нужно чем-то подтвердить. Обещания лечебного действия на пищевой продукции под запретом, их лучше показать юристу.
