# GEO-монитор: попадает ли kovtun.studio в нейроответ Яндекса

Замер того, ради чего пишется весь блок AI-SEO. Позиции в выдаче тут ни при чем:
скрипт задает Яндексу те же вопросы, что задают люди, и смотрит список источников,
на которых нейросеть построила ответ. Есть в списке kovtun.studio — попали, нет — не попали.

## Что где лежит

| Файл | Что это |
|---|---|
| `docs/ai-seo/geo-queries.json` | вопросы прогона: id темы из ядра, запрос Wordstat с частотностью, сам вопрос |
| `scripts/geo-monitor.mjs` | сам скрипт |
| `_geo.bat` | запуск на Windows (обертка с PATHEXT, иначе node не находится) |
| `docs/ai-seo/geo-log/ГГГГ-ММ-ДД.json` | полный ответ по каждому вопросу: текст, все источники, кто процитирован |
| `docs/ai-seo/geo-log/history.csv` | одна строка на вопрос за прогон — по ней смотрится динамика |

## Настройка (один раз)

1. Консоль Yandex Cloud → каталог `b1g7nj7oqis0bkrriudp` → **Сервисные аккаунты** → создать,
   например `geo-monitor`.
2. Назначить ему роль **`search-api.webSearch.user`** на каталог. Других ролей не нужно.
3. У сервисного аккаунта → **Создать новый ключ** → **API-ключ**. Область действия можно
   ограничить Search API. Ключ показывается один раз.
4. Создать файл `%USERPROFILE%\.yc-geo.env` (вне репозитория, в git не попадает):

   ```
   YC_SEARCH_API_KEY=<ключ>
   YC_FOLDER_ID=b1g7nj7oqis0bkrriudp
   ```

## Запуск

```
_geo.bat --dry            список вопросов и смета, без обращений к API
_geo.bat --only A1.4      один вопрос — на нем и проверяем, что ключ живой
_geo.bat                  полный прогон
```

## Деньги

Генеративный ответ стоит 5,08 ₽ за запрос (5 080 ₽ за 1 000, с НДС). Прогон из 14 вопросов —
около 71 ₽. Раз в две недели выходит примерно 150 ₽ в месяц. Чаще смысла нет: нейроответ
меняется медленно, а статьи выходят два раза в месяц.

## Как читать результат

- **ЕСТЬ, источник №N** — сайт в списке. Чем меньше N, тем выше нас поставили.
- **`used: true`** — фрагмент реально пошел в текст ответа, а не просто попал в подборку.
  Это верхняя планка, к ней и идем.
- **нет, N источников: домен, домен** — кого Яндекс цитирует вместо нас. Это и есть список
  конкурентов по конкретной теме, полезнее любой аналитики позиций.

Правило: замер делается **до** публикации статьи по теме и через 3-4 недели после. Иначе
непонятно, что дала статья.
